## Prototype: MVP operations

### Purpose
Completes the first wireframe round with the remaining operational screens of the Emaús MVP.

### Screens
- Ministry profile: summary, leaders, current participants, historical-vínculo and upcoming-meeting tabs.
- Meeting: meeting details, audience, attendance summary and one-tap attendance cycle.
- Users and access: administrative table with person, role, status and authorized ministries.
- Empty state: contextual message with one primary action.

### Confirmed interaction rules
- Attendance cycles by touching a person row: not confirmed (white) → present (green) → absent (red) → not confirmed.
- Success feedback is discreet; sensitive actions should use confirmation dialogs in the future implementation.
- The prototype uses fictional data only and is a design artifact, not application code.
